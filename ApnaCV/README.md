# ApnaCV

**Apna Resume. Apni Pehchaan.**

ApnaCV is a simple resume builder website that allows users to create professional resumes using different templates.

## Features

* Simple 4-question onboarding
* 60 different resume templates
* Live resume preview
* Add, edit, and delete resume information
* Create custom sections
* Save resume in browser
* Download resume as PDF
* Smooth animations
* Responsive design

## Technologies

* HTML
* CSS
* JavaScript
* LocalStorage

## How to Run

1. Download the project.
2. Open the `ApnaCV` folder.
3. Open `index.html` in a browser.
4. Start creating your resume.
