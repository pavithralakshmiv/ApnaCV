# ApnaCV

**Apna Resume. Apni Pehchaan.**

ApnaCV is a simple and user-friendly resume builder website that helps users create professional resumes using a variety of customizable templates.

## Features

* Simple 4-question onboarding
* 60 different resume templates
* Live resume preview
* Add, edit, and delete resume information
* Create custom resume sections
* Save resume data in the browser
* Download resume as PDF
* Smooth animations and transitions
* Responsive design for different screen sizes

## Technologies Used

* **HTML** – Structure of the website
* **CSS** – Styling, layouts, animations, and responsive design
* **JavaScript** – Resume builder functionality and interactions
* **LocalStorage** – Saving resume information directly in the browser

## How to Run

1. Download or clone the project.
2. Open the `ApnaCV` folder.
3. Open `index.html` in any modern web browser.
4. Start creating your resume.

No server or additional installation is required.
